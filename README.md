# Anti-Poaching System

A wildlife conservation and anti-poaching management system.

## Features

- Predictive analytics for poaching hotspots
- Community reporting via mobile/web
- Real-time incident tracking
- Species database
- Ranger patrol management

## Tech Stack

- Backend: FastAPI, Python, PostgreSQL/PostGIS
- Frontend: React, Tailwind CSS, Leaflet
- ML: Scikit-learn, Pandas

## Quick Start

\`\`\`bash
docker-compose up -d
